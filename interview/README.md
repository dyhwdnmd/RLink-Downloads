按模块整理项目相关知识。后续每次模拟面试后持续更新。

## 专题

- [AI 场景感知与 WebRTC 画质优化](07-AI场景分析与画质优化.md)

## 计划覆盖的模块

- 项目整体架构与模块职责
- C++ 基础、现代 C++ 特性与对象生命周期
- 多线程、同步原语与任务队列
- 计算机网络、WebRTC、ICE、STUN/TURN、信令
- 音视频采集、编码、码率控制、解码与渲染
- Windows 桌面采集、Qt 与系统接口
- 文件传输、远程剪贴板与多人房间
- AI 场景分析与自适应画质策略
- 调试、性能分析、异常处理与安全性

## 面试练习原则

每个问题尽量按“问题背景 → 原理 → 项目中的实现 → 取舍与局限 → 如何验证”组织回答。对没有通过源码确认的实现细节，明确标记，不把推测当作项目事实。
